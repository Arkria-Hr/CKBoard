# CKBoard 平板白板

把老旧平板变成网课手写白板的方案。**平板不需要安装任何 App**，用自带浏览器打开一个网页即可；电脑端只需运行一个 Python 服务。

## 方案选择

| | 白板镜像（首选） | 触控板（保底） |
|---|---|---|
| 原理 | 平板书写 → WiFi 实时同步到电脑浏览器 | 平板触摸 → 映射为电脑鼠标 |
| 教学效果 | 平板和电脑看到同一张纸，内容完全对应 | 用电脑上任意软件（如 PPT 批注）书写 |
| 需要 | 平板浏览器能打开网页 | 同上 |

两套都做了，任选。通信走**家用 WiFi**（有线 USB 是 HiSuite 存储通道，不参与实时通信）。

## 快速开始（三步）

1. **电脑上**双击 `start.bat`（或命令行 `python server.py`），记下窗口中显示的地址，如 `http://192.168.1.107`。首次运行若弹出防火墙提示，勾选"专用网络"→"允许访问"。
2. **平板上**（连同一 WiFi）打开浏览器，输入电脑显示的地址 → 出现白板页面。
3. 电脑会自动打开"镜像窗口"（右上角状态显示"已连接"即可）。把这个镜像窗口共享到腾讯会议即可上课。

## 白板用法（平板）

- **单指**：写字（工具栏选红/黑/蓝笔，或擦除）
- **✋ 漫游**：点一下进入漫游模式，单指拖动画布（不写字）；再点一下退出
- **双指**：缩放 / 平移纸张（纸面无限延展，无边界）
- **擦除**：橡皮按住拖动，真擦除（擦过的地方干净，重新写字仍可写）
- 工具栏：红 / 黑 / 蓝 / 擦除 / 撤销 / 清空 / 漫游 / 复位 / 全屏
- 页面右上角状态点：绿色=已连接，红色=未连接（自动重连）

## 笔记持久化

- 所有笔记自动保存到电脑 `data/board.json`，**服务重启、电脑重启后笔记不丢**
- 平板刷新或重新打开页面时，自动恢复全部笔记和纸张位置
- 若笔记位置不在屏幕范围内，会自动把纸面移动到笔记处

## 电脑镜像窗口

- 打开 `http://127.0.0.1/?role=viewer`（start.bat 会自动打开）
- 该窗口实时显示与平板**完全对应**的纸面（含缩放位置）
- 按 `⛶ 全屏` 按钮或 F11 全屏后共享，学生看得更清楚
- 若网络断开后平板重新连接，平板本地内容会自动全量同步回镜像窗口

## 触控板模式（保底）

平板浏览器打开 `http://<电脑IP>/tp`（也可用 `/touchpad.html`）：

- **画模式**：手指按下=按住鼠标左键（可配合电脑上任何画图/批注软件书写）
- **移动模式**：只移动光标不点击（用于挪动鼠标）
- **⏏ 松开左键**：鼠标左键卡住时点一下释放

## 目录结构

```
CKBoard/
├── server.py        # 服务端（零第三方依赖：HTTP + WebSocket + 鼠标注入）
├── start.bat        # 双击启动
├── web/
│   ├── index.html   # 白板页（author 书写 / viewer 镜像）
│   ├── app.js       # 白板逻辑
│   └── touchpad.html# 触控板模式页
```

## 常见问题

- **平板打不开页面**：确认平板与电脑在同一 WiFi；确认电脑防火墙允许（见上）；试试换 `http://192.168.1.107` 的其他候选 IP。
- **镜像窗口无内容**：确认镜像窗口顶部状态点是绿色；平板书写后 1~2 秒内应出现。
- **平板浏览器太老打不开**：在白板页失败时，改用触控板模式（大多数老浏览器都能开网页）。
- **笔迹粗细**：笔宽按纸张坐标存储，缩放后随纸张同比例缩放，符合真实纸张手感。

## 技术说明

- 通信：WebSocket（手写 RFC6455 实现），默认端口 80（被占用自动回退 8180），JSON 协议
- 笔迹以世界坐标存储于服务端，自动持久化到 `data/board.json`（防抖 1 秒写盘，退出时强制保存）
- 新加入的镜像端自动获取全量状态；平板刷新/重开自动恢复笔记
- 笔画增量传输（60ms 节流），视口同步（120ms 节流）
- 橡皮采用 `destination-out` 合成，真擦除（重绘后不会"复活"）
- 触控板模式通过 Windows `SendInput` 注入鼠标（绝对坐标），无驱动依赖
